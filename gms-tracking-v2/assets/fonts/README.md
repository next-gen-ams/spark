# DM Sans

The unmodified variable font is bundled locally so the dashboard does not depend on external font services.

- Source: https://github.com/google/fonts/tree/main/ofl/dmsans
- File: `DMSans[opsz,wght].ttf`, retrieved 2026-09-05.
- Licence: SIL Open Font License 1.1; see `DM-Sans-OFL.txt`.
- CSS family: `DM Sans`; variable weight 100–1000 and optical size.
- Chinese text uses the system Chinese fallback; the GMS logo remains the original artwork.
