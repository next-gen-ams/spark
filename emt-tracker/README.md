# EMT Tracker

GMS Executive Management Team workspace for fortnightly agendas, decisions and follow-up reminders.

- Published path: `https://spark.kmt.global/emt-tracker/`
- Microsoft sign-in: tenant-scoped Entra SPA using delegated `User.Read`
- Current Microsoft status: application registration pending; the site does not simulate a connected account
- Outlook mail and calendar delivery: not enabled yet
- Data: illustrative in-browser prototype data; no persistent EMT database is connected yet

The compiled static site is committed in this directory so it can be served by the existing Spark GitHub Pages deployment.
